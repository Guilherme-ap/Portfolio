# Portfólio — Guilherme Alves

Portfólio estático em HTML, CSS e JavaScript puro.

## Executar

Abra `index.html` no navegador ou execute:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

O layout não depende mais de Bootstrap ou MDB. O arquivo `mdb.min.css` foi mantido no repositório apenas para preservar o histórico.
